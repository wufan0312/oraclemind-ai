# 玄镜 OracleMind · AI 服务 · RAG 检索增强依赖（本地 / 自托管用）
#
# 用法：pip install -r requirements-rag.txt
#
# 为什么单独一份：
#   chromadb 的传递依赖体积巨大（kubernetes ~84MB + onnxruntime ~45MB +
#   chromadb_rust_bindings ~61MB + numpy ~55MB，实测 site-packages 合计 400MB+），
#   放进去会让 Vercel 函数超出体积上限（Hobby 未压缩约 250MB）而无法加载。
#   代码里 chromadb 是惰性 + 容错导入（src/services/retrieval.py: get_collection()），
#   缺包时 RAG 自动降级为空检索 —— 因此 Vercel 生产**无需**安装它。
#
#   本地开发或自托管（Railway / Render / Fly.io，支持持久盘、无 500MB 限制）要用
#   RAG 时，装本文件即可；并把 RETRIEVAL_ENABLED=true、CHROMA_PERSIST_DIR 指向可写目录。

-r requirements.txt

# RAG 向量数据库
chromadb>=0.5.0
