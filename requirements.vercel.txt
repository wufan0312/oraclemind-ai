# 玄镜 OracleMind · AI 服务（Python）· Vercel 专用精简依赖

# 用途：Vercel 函数有 500MB 包体硬上限。完整版 requirements.txt 含 chromadb，
# 其传递依赖（kubernetes ~84MB + onnxruntime ~45MB + chromadb_rust_bindings ~61MB
# + numpy ~55MB）合计极易超限，导致部署失败或函数加载失败（FUNCTION_INVOCATION_FAILED）。
#
# 生产环境 RAG 默认关闭（RETRIEVAL_ENABLED=false，见 .env.production），
# 且 chromadb 在本仓为惰性 import（src/services/retrieval.py:61，仅 RAG 触发时 import），
# 因此 Vercel 上无需安装它即可正常运行全部解读能力。
#
# 启用方式（一步）：
#   在 Vercel 项目 Settings → Build & Development Settings → Install Command
#   改为：pip install -r requirements.vercel.txt
#   （不配置则 Vercel 默认读 requirements.txt，仍会安装 chromadb，体积风险依旧。）
#
# 若日后要在 Vercel 开启 RAG，请勿用此文件，改走支持持久盘/无 500MB 限制的主机
# （Railway / Render / Fly.io），详见 DEPLOYMENT.md §3。
